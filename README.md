# Voice Controlled WhatsApp Messenger

A Python-based voice assistant that can automatically send WhatsApp messages using speech recognition and desktop automation.

## Features

- Voice-controlled messaging
- Speech-to-text using Google Speech Recognition
- Text-to-speech responses
- Opens WhatsApp Desktop automatically
- Searches contacts automatically
- Sends messages hands-free
- Beginner-friendly Python project

## Technologies Used

- Python
- pyttsx3
- speech_recognition
- pyautogui
- PyAudio
- WhatsApp Desktop

## How It Works

1. The assistant asks for the contact name.
2. User speaks the contact name.
3. WhatsApp Desktop opens automatically.
4. The assistant searches for the contact.
5. User speaks the message.
6. The message is typed and sent automatically.
